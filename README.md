# 🚀 CareerPilot AI

**Your Intelligent Career Companion**

CareerPilot AI is an AI-powered Resume Intelligence Platform that helps students and job seekers improve their resumes, prepare for interviews, analyze ATS compatibility, compare resumes with job descriptions, and generate personalized cover letters using Google Gemini AI.

---

## 📌 Features

### 📄 Resume Parser

* Upload PDF or DOCX resumes
* Extract candidate information automatically
* Extract:

  * Name
  * Email
  * Phone Number
  * Skills
  * Education
  * Experience
  * Projects
  * LinkedIn
  * GitHub

---

### 🤖 AI Resume Summary

Generate an AI-powered professional summary of the uploaded resume including:

* Candidate Profile
* Strengths
* Weaknesses
* Career Recommendations

---

### 📊 ATS Analysis

Analyze resume quality for Applicant Tracking Systems (ATS).

Provides:

* ATS Score
* Strengths
* Suggestions
* Resume Improvement Tips

---

### 💼 AI Interview Questions

Automatically generates interview questions based on the candidate's resume.

Includes:

* Technical Questions
* Project-Based Questions
* HR Questions

---

### 🎯 AI Job Match

Compare the latest uploaded resume with any Job Description.

Displays:

* Match Percentage
* Matched Skills
* Missing Skills
* AI Suggestions

---

### 📈 ATS Improvement

Provides AI-generated recommendations to improve ATS compatibility.

Includes:

* ATS Score Improvement
* Missing Keywords
* Resume Improvements
* Technical Skill Suggestions
* Career Advice

---

### ✉ AI Cover Letter Generator

Generate a personalized professional cover letter using:

* Candidate Resume
* Job Description

Supports:

* Copy Cover Letter
* Print Cover Letter

---

### 📚 Resume History

Stores every uploaded resume.

Displays:

* Upload Date
* ATS Score
* Candidate Details
* Resume Information

---

### 🔐 Authentication

* User Registration
* User Login
* Secure Password Hashing
* Flask Session Management

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/CareerPilot-AI.git
```

```bash
cd CareerPilot-AI
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Start MySQL

Create the required database and tables.

---

## Configure Gemini API

Open:

```
ai_service.py
```

Replace the API key with your own Google Gemini API key.

---

## Run Project

```bash
python app.py
```

Open:

```
"https://careerpilot-ai-voux.onrender.com"
```
